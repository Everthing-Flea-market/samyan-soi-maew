# สามย่านซอยแมว · ผังล็อกร้านค้า 3D

หน้าเว็บผังล็อกร้านค้าแบบ 3D ของงาน **สามย่านซอยแมว** · 13–15 พ.ย. 2569 · 16:00–20:00 น.

- เปิด `index.html` (ผ่านเว็บเซิร์ฟเวอร์ เช่น GitHub Pages) เพื่อดูผัง
- สถานะล็อก (ว่าง / จองแล้ว) ดึงจากตาราง `booths` ใน Supabase ด้วยคีย์สาธารณะแบบอ่านอย่างเดียว ทุก 30 วินาที
  ถ้าเชื่อม Supabase ไม่ได้ จะใช้ `data/booths.json` แทน
- หน้านี้ดูได้อย่างเดียว การแก้สถานะทำโดยทีมงานผ่าน Claude เท่านั้น
